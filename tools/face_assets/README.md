# Recursos anatômicos

A cabeça em `head.obj` é uma adaptação da malha hm08 do MakeHuman. Foi
recortada na altura do pescoço, triangulada e simplificada. Globos oculares,
íris, pupilas e sobrancelhas foram acrescentados para o Football. A paleta
de materiais é gerada pelo editor.

O arquivo `morphs.json` contém deslocamentos positivos e negativos
transferidos para os vértices da malha simplificada a partir de 20 pares
de controles anatômicos do MakeHuman. Os grupos de origem são `cheek`,
`chin`, `eyes`, `nose`, `mouth` e `ears`. Os controles bilaterais
combinam os dois lados. O espaçamento dos olhos é ajustado pelo Football.

`a8bc2d54ff0ac92e78ff71431b1023eda42bf482`. O SHA-256 de
`makehuman/data/3dobjs/base.obj` na origem é
